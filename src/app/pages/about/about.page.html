About

Engineered for clean delivery from day one

This starter focuses on robust defaults: clear routing, composable standalone components, strict TypeScript, and utility-first styling.

It is optimized for small teams that need a polished user interface without introducing unnecessary dependencies.

Core Principles

  • Focused Components: Keep features isolated and easy to test.
  • Responsive by Default: Mobile-first classes with progressive enhancement.
  • Simple Deploy Path: GitHub Actions workflow included for Pages.
